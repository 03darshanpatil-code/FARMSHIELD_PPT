# FARMSHIELD — Interactive Presentation Platform

An interactive, cinematic presentation platform for **FarmShield**, an AI-powered
unified agricultural ecosystem. Six team members present one continuous story —
from the problems facing Indian farmers, through intelligent crop care, market
intelligence, weather and soil insights, government services and supply-chain
trust, to a final AI assistant and impact section.

> **Demo application:** everything runs on frontend-only mock/demo data. There is
> no backend, no database, no authentication, and no external API required.

## Technology

- **React** + **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Framer Motion**
- **React Router**
- **Lucide** icons

## Sections

- **The Problem & FarmShield Vision** — Agriculture today, farmer challenges, the core problem, and the FarmShield solution.
- **AI & Smart Crop Care**
  - AI Disease Detection
  - Fertilizer Marketplace
  - Crop Simulator
- **Market & Farmer Economy**
  - Market Price Forecasting
  - Krishi Setu
- **Smart Agriculture Intelligence**
  - Weather Intelligence
  - Soil Intelligence
- **Farmer Services & Trust**
  - Government Schemes
  - HarvestID
- **AI Assistant & Impact**
  - Kisan Times
  - Plant Doctor AI
  - Multilingual AI
  - FarmShield Impact

All prices, forecasts, weather, soil reports, news, and AI answers are simulated
for presentation purposes and are clearly labeled as demo data.

## Local Setup

```bash
npm install
npm run dev
```

Open the printed local URL to explore the presentation.

## Build

```bash
npm run build
```

Produces a static build in `dist/`.

## Environment Variables

No environment variables are currently required.
